01

Two ideas两个想法

Two claims carry the project. Each comes with evidence from a real run.

项目建立在两个主张上，每个都附有真实 run 的证据。

Idea I · symbolic想法一 · 符号

Code is enough.

代码就够了。

A scientific model can be a program: rules, equations and algorithms in numpy and scipy, with no neural network inside. Code is symbolic. You can read it, check it, test it and edit it, and its describe() states every term and what it means.

科学模型可以就是一个程序：规则、方程、算法，只用 numpy 和 scipy，里面没有神经网络。代码是符号化的，可以读、可以查、可以测试、可以改，describe() 会写明每一项及其含义。

The goal is to match SOTA networks such as AlphaFold, ESM and MatterGen on their own benchmarks, on the same held-out cases.

目标是在 AlphaFold、ESM、MatterGen 这类 SOTA 网络自己的 benchmark 上，在同样的留出 case 上与它们持平。

  • 176lines in the best program最好程序的行数
  • 79features in the model模型里的特征数
  • 0neural networks inside里面的神经网络

Idea II · neural想法二 · 神经

Self-improvement maxes out the code.

自我改进把代码榨到极致。

The LLM writes the program. A loop scores every version on held-out data, keeps what holds up and feeds the evidence back. An inner search tunes the knobs at machine speed. The LLM makes the changes a search cannot: new terms and new forms. A new run starts from the best program of the last.

LLM 写出程序。循环在留出数据上给每个版本打分，留下站得住的，再把证据交回去。内层搜索按机器速度调旋钮；LLM 做搜索做不到的改动：新的项、新的形式。新的 run 从上一个 run 的最好程序接着做。

The aim is code-maxing: the best performance a program can reach.

目标是 code-maxing：让程序能达到的性能最大化。

  • 25evaluations次评测
  • 2.8 hof wall-clock time耗时
  • +0.062Spearman on val, 0.308 to 0.370val 上的 Spearman，0.308 升到 0.370
